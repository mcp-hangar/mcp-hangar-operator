**controller:** the operator writes `spec.initData` byte for byte into the pod's `io.katacontainers.config.hypervisor.cc_init_data` annotation (gzip-compressed, then base64-encoded, as Kata reads it). It publishes the SHA-256, SHA-384 and SHA-512 of those bytes as `status.initDataDigests` (ADR-031). It now registers a key-pinned server that declares `issuance: kbs-attested` with a core that advertises `declared_key_issuance`, carrying the declaration in the key list. An older core still gets no such server.
