**controller:** a remote `MCPServer` with `spec.tls.peerIdentity` is registered with core together with its key list (ADR-030 §4). The operator registers it only when core lists the `peer_identity` capability in `GET /api/system` and `hangar.url` is `https`. A declared `issuance` is not registered either, because core does not record it yet. In each of these cases the CR reports `Degraded` with reason `PeerIdentityNotCarried`. A changed endpoint or key list is delivered to core in place with `PUT`, keeping the server's identity, rather than by removing the server and registering it again. A refused delivery is retried. A container-mode `MCPServer` with a peer identity is still held without a pod.
