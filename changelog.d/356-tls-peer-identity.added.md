**api:** `MCPServerSpec` gains `tls: {peerIdentity: {keyRef, spkiSha256, issuance}, maxConnectionAge}` (ADR-030), validated by the apiserver with no webhook. `spkiSha256` takes one to sixteen key pins, each in the canonical `sha256:` plus 64-lowercase-hex form. `keyRef` is required. `issuance` accepts only `kbs-attested`. `maxConnectionAge` must be positive and needs a `peerIdentity`. A remote key-pinned server needs an `https` endpoint. An `MCPDiscoverySource` whose `providerTemplate` carries a `peerIdentity` is refused, since every server it yields would share one key list. This operator does not yet register a key-pinned server with its key list, so a CR that declares `peerIdentity` is neither run nor registered. It reports `Ready=False` with reason `PeerIdentityNotCarried`, instead of being served as a plain server.
