**controller:** moving a server core discovered from an `MCPServer`'s own pod to a key-pinned registration now also needs core to report the server's provenance as `discovery` (core 2.32.0 or newer). A server under the same name that core says a human registered is reported as `NameTaken` and left alone, even while the CR's Deployment still stamps its pods for discovery. A core that reports no provenance is judged by the Deployment alone, as before.
