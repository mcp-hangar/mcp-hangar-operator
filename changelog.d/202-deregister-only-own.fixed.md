**controller:** deleting a `mode: remote` MCPServer no longer deletes the server of the same name in core. Such a CR only mirrors a server declared elsewhere, usually core's config, and deleting it took that server out of core until the next reload. The operator now deregisters a remote server only when the CR carries `mcp-hangar.io/registered-by: operator`, and emits a `DeregistrationSkipped` Event otherwise. Container-mode servers are deregistered as before.
