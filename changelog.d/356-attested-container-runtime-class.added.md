**api:** a container-mode `MCPServer` whose `spec.tls.peerIdentity.issuance` is `kbs-attested` must set `spec.runtimeClassName` (ADR-030 §4, T14). An attested key is released only to a guest in a confidential runtime. This is a precondition, not evidence: any runtime class satisfies it, and none attests anything by itself. A remote server, or a container whose keys the operator manages, needs no runtime class.
