**controller:** `manager render < mcpserver.yaml` prints the Deployment the operator would apply for a container-mode MCPServer (ADR-031). For a `kbs-attested` server, that output is the input Kata's `genpolicy` needs. Run it from the operator image of the release you deploy, against the stored object (`kubectl get mcpserver NAME -o yaml`), whose generation the pod template carries. A golden-file test pins the rendering of a `kbs-attested` server. Any change to it comes with an upgrade note.
